# 🍽️ AddisBite

### Your Cravings. Your City. Your Bite.

AddisBite is a food-ordering mobile application built with **Flutter and Dart**, designed to make discovering food and managing orders simple and convenient. Inspired by the food culture of Addis Ababa, the project aims to bring a modern digital food-ordering experience to users, with a focus on usability, personalization, and a clean interface.

## ✨ Features

- 🥘 **Food Ordering Experience** — Explore food options and build your order.
- 🛒 **Shopping Cart** — Add items to your cart and manage your selections.
- ❤️ **Favorites** — Save favorite items for quick access.
- 📦 **Order Management** — Manage and keep track of orders within the app.
- 🔐 **Authentication State** — Manage and persist authentication-related state.
- 🌙 **Light & Dark Mode** — Switch between light and dark themes.
- 💾 **Local Data Persistence** — Retain supported app data between sessions.
- ⚡ **State Management** — Use Provider to keep application state organized and reactive.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Flutter | Cross-platform application development |
| Dart | Application programming language |
| Provider | State management and reactive UI updates |
| SharedPreferences | Local preference and lightweight data persistence |
| Material Design | UI components and application styling |

## 📱 Application Architecture

The application is organized into separate components to keep responsibilities clear and make future development easier.

- `constants/` — Application-wide constants and configuration
- `providers/` — State management for authentication, cart, favorites, orders, and settings
- `screens/` — Application screens, including the splash screen
- `services/` — Storage initialization and local persistence
- `theme/` — Light and dark theme configuration
- `main.dart` — Application entry point and provider initialization

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart)
- [Git](https://git-scm.com/)
- Android Studio, VS Code, or another Flutter-compatible IDE

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/addisbite.git
   ```

2. Navigate to the project directory:

   ```bash
   cd addisbite
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Check your development environment:

   ```bash
   flutter doctor
   ```

5. Run the application:

   ```bash
   flutter run
   ```

To run the app on Windows, Android, or another supported platform, make sure the required platform development tools are configured.
